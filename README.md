# NEW AIR — releases

Instaladores do **NEW AIR**, app desktop (Windows 10/11) para controlar ar-condicionado Elgin HJ/KO pela rede local.

- Baixe o instalador mais recente em [Releases](https://github.com/ArthurKairan/new-air-releases/releases/latest) (`NEW-AIR_<versão>_x64-setup.exe`).
- O app instalado verifica este canal sozinho (`latest.json`) e só aceita pacotes assinados com a chave do projeto.

Este repositório contém apenas os binários publicados; o código-fonte é mantido em repositório privado.
